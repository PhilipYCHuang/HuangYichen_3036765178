# Fama–French (1993) Three-Factor Construction — Replication & Extension

Individual project for **ECON6067**. This repository reconstructs the monthly
**MKT-RF, SMB and HML** factors for 2000–2025 from raw CRSP / Compustat data,
compares them against the official Kenneth French series, and adds an
independent extension (a momentum factor and a three- vs. four-factor model
comparison).

## Data acquisition (raw data is NOT stored in this repo)

The analysis uses four files from two course packages. Download
`02_Monthly_Stocks_and_Factors.zip` and `04_Supplementary_Data.zip` from the
course portal, then copy the four CSVs below into `data/raw/`, keeping their
filenames unchanged:

| File | From package |
| --- | --- |
| `monthly_stock.csv` | 02 |
| `F-F factors and RF.csv` | 02 |
| `Compustat.csv` | 04 |
| `CCM.csv` | 04 |

The raw CSVs are restricted (CRSP / Compustat) and are excluded via
`.gitignore`; only the folder READMEs are committed. See `data/raw/README.md`.

## Reproducing the results

With the four raw files in `data/raw/`, run:

```bash
python code/run_all.py
```

This executes the six numbered scripts in order — `01_data_prep.py` →
`02_variable_construction.py` → `03_portfolio_sorting.py` →
`04_factor_construction.py` → `05_validation.py` → `06_extension.py` — each
reading the previous step's output from `data/processed/` and writing to
`outputs/`. No manual editing of data or code is required.

Main outputs:

- `outputs/FF3_constructed.csv` — reconstructed monthly MKT-RF / SMB / HML
- `outputs/tables/` — descriptive stats, correlations, tracking regressions,
  and the 3- vs 4-factor GRS model comparison
- `outputs/figures/` — cumulative-return curves and the extension's alpha chart

## Key methodological choices

Documented in detail in `report.pdf`; summarised here:

- **Universe**: US common equity only — `SecurityType=EQTY`, `ShareType=NS`,
  `USIncFlg=Y`, `IssuerType=CORP`, exchange in NYSE / NYSE American / NASDAQ
  (`PrimaryExch` in `N/A/Q`). REITs, ADRs, funds and foreign firms are excluded.
- **Market equity**: `ME = MthCap / 1000` (millions of USD).
- **Book equity**: `BE = SEQ + TXDITC - preferred`, preferred = redemption value
  (`pstkrv`), else liquidation (`pstkl`), else carrying (`pstk`); if `SEQ` is
  missing, `CEQ + PSTK` is used.
- **Book-to-market**: `BM = BE(fiscal year t-1) / ME(Dec t-1)`, positive `BE` only.
- **Link table**: primary/conditional-primary (`LINKPRIM` in `P/C`) and
  current/unresearched (`LINKTYPE` in `LC/LU`) links, with link dates applied.
- **Portfolio sorts**: each June, size split at the NYSE median and BM split at
  the NYSE 30/70 percentiles, value-weighted monthly returns.
- **Factors**: `SMB = mean(S/L,S/M,S/H) - mean(B/L,B/M,B/H)`,
  `HML = mean(S/H,B/H) - mean(S/L,B/L)`, `MKT-RF = vwretd - RF`.
